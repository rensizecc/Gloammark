# Changelog

## 1.4.0

- Added structured README.md import with safe fallback to Custom Markdown.
- Added direct import from public GitHub repositories.
- Added local multi-project library with open, save, delete, and project export.
- Added README validation for common structural, URL, badge, configuration, and export issues.
- Added Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S, undo, and redo workflows.
- Added native desktop file opening for Markdown and Gloammark project files.
- Added expanded README presets.
- Added macOS and Linux packaging targets.
- Added tag-driven GitHub Actions release builds for Windows, macOS, and Linux.
- Improved rendered preview links and heading anchors.
- Switched editable project files to the .gloammark extension while keeping legacy JSON import support.

## 1.3.0

- Expanded the technology catalog and custom technology support.
- Added Requirements, GitHub Alert, Code Snippet, Resources, Contributing, and Custom Markdown blocks.
- Added project import and export foundations.

## 1.2.0

- Added configurable badge colors, spacing, previews, and ordering.

## 1.1.0

- Added rich text controls, description fields, gallery, FAQ, table of contents, drag and drop, undo, and redo.
